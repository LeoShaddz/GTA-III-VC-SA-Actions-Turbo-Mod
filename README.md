# GTA III / Vice City/ San Andreas Actions Turbo Mod

This is the old "Bike Turbo" mod, expanded and renamed.

This mod adds a "turbo" effect to certain in-game actions, such as pedaling a bicycle faster, performing melee attacks, and training at the gym. For III and VC, it’s melee-only, since those games don’t have bicycles or gyms.

In other words, actions that previously required pressing the button multiple times can now be performed by holding the button down.

To enable or disable the mod, you can do this in the game's controller setup or type "ATURBO" during the gameplay.

This mod is customizable, in the .ini file, you can disable the turbo for each action individually, in case you want to disable it for just one action while keeping the others enabled.

The new text in the game's controls options can be customized via the .ini file, in case you wish to translate it into another language.

# Installation 

**III**: 

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.III.Melee.Turbo.Mod.v1.0.zip"
3. Copy the "Melee Turbo" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**VC**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.VC.Melee.Turbo.Mod.v1.0.zip"
3. Copy the "Melee Turbo" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**SA**: 

1. Install the Silent's Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.SA.Actions.Turbo.Mod.v1.2.zip"
3. Copy the "Actions Turbo" folder into the "modloader" folder, which is located in your game's root directory.
4. Done
